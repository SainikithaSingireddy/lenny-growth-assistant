# The Lenny Growth Assistant

A full-stack Retrieval-Augmented Generation (RAG) application built for the Oogway Labs Forward Deployed Engineer take-home assignment.

## Tech Stack

- Frontend: Next.js + Tailwind CSS
- Backend: FastAPI
- Database: PostgreSQL + pgvector
- Local LLM: Ollama (Llama 3.2 3B)
- Cloud LLM: OpenAI
- Deployment: Docker Compose
